# Cellera — прототип сайта

Соли Шюсслера от завода BJAIN. Кликабельный прототип.

**Смотреть:** https://tukranchuk82-lang.github.io/cellera-site/

## Что внутри

`index.html` — весь сайт одним самодостаточным файлом: стили, картинки
и логика внутри. Никакой сборки не нужно, открывается двойным щелчком.

Разделы: главная, подбор с ИИ-помощником, каталог (12 солей,
30 комплексов, наборы), 36 состояний, о методе, как принимать,
где купить, о компании.

Дизайн-система взята из приложения Cellera без изменений:
Cormorant Garamond и Nunito Sans, бумажный фон, охряный акцент.

## Папки

- `prototype/` — тот же файл плюс исходные и обработанные фотографии
- `hero/` — ранняя версия первого экрана
- `docs/` — рабочие материалы Анны Шароновой
